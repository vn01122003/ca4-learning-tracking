# CA4 Study Tracker

Website tĩnh dùng HTML, CSS và JavaScript thuần.

## Chạy trên máy tính
1. Giải nén thư mục.
2. Mở `index.html` bằng Chrome, Edge hoặc Firefox.
3. Không cần cài đặt server, database hay API.

## Cấu trúc
- `index.html`: cấu trúc giao diện.
- `css/style.css`: giao diện Academic, responsive, không animation.
- `js/app.js`: dữ liệu kế hoạch, checklist và xử lý lưu trạng thái.

## Tính năng
- Dashboard tiến độ 84 buổi / 252 giờ.
- Kế hoạch 12 tuần, checklist 7 buổi mỗi tuần.
- Theo dõi 8 nhóm tài liệu A–H.
- Theo dõi mức độ kiến thức L1–L5.
- Sổ lỗi sai có ngày ôn lại.
- Tự lưu dữ liệu bằng LocalStorage của trình duyệt.

## Lưu ý
Đây là bản frontend tĩnh. Dữ liệu nằm trong LocalStorage trên trình duyệt và thiết bị đang dùng; không tự đồng bộ giữa nhiều thiết bị. Hãy sao lưu dữ liệu trình duyệt nếu cần giữ tiến độ lâu dài.
